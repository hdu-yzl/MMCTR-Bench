# EB-NeRD generated data

The dataset catalog uses `canonical-v4/`: 56 categorical/bucketed exposure fields in the shared
ID embedding table, history length 5, and 10% whole-impression local-test sampling with seed 2025.
Train/validation/test contain 2,325,624 / 260,123 / 292,271 candidate rows.

Generated arrays, original ID mappings, fitted attribute vocabularies, and manifests remain
local with the data.
Only placement documentation and preprocessing source are published.

See [the processing protocol](../../../docs/data.md#eb-nerd) for conversion, sampling,
verification, and the distinction from the official challenge test.
